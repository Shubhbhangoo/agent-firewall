# v1.8 CLI Reference

The `firewall` command now covers both configuration/inspection (v1.7)
and the security flight recorder workflow (v1.8).

## v1.8 commands

### record

Record a demo agent session through the real SDK and write a portable,
verifiable security artifact:

```bash
firewall record --out agent-session.afw --agent agent-demo
```

The recording is genuine: the SDK issues, authorizes (allow + deny),
and applies containment, and the recorder captures everything
post-decision. The artifact verifies immediately.

### inspect

Summarize an artifact without verifying it (session, counts, recorder
identity, timeline):

```bash
firewall inspect session.afw
firewall inspect session.afw --json
```

### verify

Independently verify integrity and signatures:

```bash
firewall verify session.afw
firewall verify session.afw --expect-recorder <fingerprint>
firewall verify session.afw --json
```

Exit status contract: `0` = verified/redacted · `1` = incomplete ·
`2` = failed/unverifiable/usage.

### replay

Security replay laboratory. Replays recorded decisions through the real
authorization pipeline in isolated workspaces, and supports
counterfactual policy analysis:

```bash
firewall replay session.afw
firewall replay session.afw --rules proposed-rules.json
firewall replay session.afw --rules proposed-rules.json --json
firewall replay session.afw --limit 50
```

Proposed rules file: `{"max_delegation_depth": 2, "trusted_issuers": ["trusted-issuer"]}`.

### timeline

Render the chronological security story:

```bash
firewall timeline session.afw
```

### trajectory

Render evidence-backed posture transitions:

```bash
firewall trajectory session.afw --json
```

### graph

Inspect the derived security relationship graph:

```bash
firewall graph session.afw
firewall graph session.afw --agent agent-a --why payments.send
firewall graph session.afw --agent agent-a --reach
```

### incident

Package an incident for sharing:

```bash
firewall incident create session.afw --title "credential access" --out incident.json
firewall incident create session.afw --title "..." --summary "..." --redact --out incident.json
```

The package bundles verification, timeline, trajectory, graph, and replay
analysis. `--redact` embeds a redacted, re-signed derivation.

### redact

Produce a redacted, re-signed artifact that still verifies:

```bash
firewall redact session.afw --out redacted.afw
firewall verify redacted.afw   # status: redacted
```

```bash
firewall init

```

## Error reporting

Errors explain **what happened**, **why it matters**, and **how to fix
it**:

```text
error: cannot read cases.json: [Errno 2] No such file or directory
```

Exit codes are predictable: `0` success, `1` meaningful negative result
(validation failure, incomplete artifact, unsafe simulation), `2` inputs
could not be used.
